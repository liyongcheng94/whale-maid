# 13 · 硬件接入学园计划(v1:接服务端+鲸鱼娘表情+圆形屏适配)

> 设备:微雪 ESP32-S3-Touch-LCD-1.46(**412×412 圆形 QSPI 屏**,ESP32-S3 + 8MB PSRAM + 16MB Flash,MAC f8:5b:1b:8d:56:00)
> 现状:官方 xiaozhi v2.6.0 固件已刷、已激活(xiaozhi.me)、WiFi 已连、唤醒/对话/天气工具全链路实测通
> 出厂固件备份:`firmware/prebuilt/waveshare_146_backup.bin`(16MB,可随时回滚)
> 目标:设备从「官方云+官方表情」切换为「**家里学园服务端 + DeepSeek 鲸鱼娘人设 + 圆形屏适配的学园表情**」

## 总览(三阶段,依赖关系)

```
阶段一 接学园服务端 ──► 阶段二 鲸鱼娘表情(圆形屏适配)──► 阶段三 联调验收
     (需:家里IP+服务端部署)      (需:阶段一通,走OTA下发资产)      (需:一二完成)
```

## 阶段一:接学园服务端(预计 1 个会话)

**原理**:设备开机请求 OTA 地址 → 拿到 WebSocket/MQTT 配置 → 换服务器只需改 OTA URL。

### 步骤
1. **家里服务端部署**(docs/03 原方案,xiaozhi-esp32-server):
   - WSL2 Ubuntu-24.04 + Docker Desktop(用户安装)
   - `git clone xiaozhi-esp32-server`(已 clone 在 src/)→ docker compose up
   - 配置 DeepSeek API key(已有,web/backend/.env 同一个 key)
2. **拿到家里 PC 局域网 IP**(用户跑 `ipconfig` 告知)
3. **改设备 OTA 地址**(两种方式二选一):
   - 方式 A(推荐):设备连上 WiFi 后,长按/连续操作进入**设置页**(或由服务端管理台添加设备后下发)——xiaozhi 固件支持 MCP `self.assets.set_download_url` 同类机制改 OTA?
   - 方式 B(确定可行):**刷入时改 NVS/固件默认 OTA_URL**——用 esptool 写入,或重新编译时 menuconfig 设 `OTA_URL=http://IP:8003/xiaozhi/ota/`
   - 方式 C(最快验证):服务端跑通后,在**同一局域网**内设备首次配网时即可被服务端发现(xiaozhi-esp32-server 支持)
4. **服务端注册设备**:管理台添加设备 → 生成激活码 → 设备重新激活到自建服务端
5. **验证**:对话走 DeepSeek(学园人设:小鲸灵/冉冉姐姐口吻)而非官方 Qwen

### 验证
- 服务端日志看到设备 MQTT/WebSocket 连入
- 设备对话回复带学园人设特征(自称小鲸灵、叫冉冉姐姐)
- 断网家里服务器 → 设备回落提示

### 风险与回滚
- 官方云账号仍保留,OTA URL 改回即回官方云
- 服务端容器挂了设备连不上 → 设备本地唤醒仍可用(离线提示)

## 阶段二:鲸鱼娘表情(圆形屏适配)

**原理**:xiaozhi v2.6.0 支持自定义表情资产包——设备有 **8MB assets 分区**(日志实证),且已注册 MCP 工具 `self.assets.set_download_url`,可以把**表情包托管在局域网/公网 URL**,设备下载后替换官方表情。

### 表情集设计(学园人设映射)
官方表情集 → 鲸鱼娘形象(圆形 412×412 安全区,有效圆径 ≈380px):

| 官方表情 | 鲸鱼娘形象 | 触发场景 |
|---|---|---|
| neutral | 小鲸灵待机(眨眼) | 默认待机 |
| happy | 开心冒泡 | 答对/夸奖 |
| laughing | 大笑翻滚 | 笑话/猜中 |
| sad | 委屈泡泪 | 答错/批评 |
| angry | 鼓腮瞪眼 | 被叫胖(彩蛋) |
| thinking | 泡泡思考 | LLM 思考中 |
| sleeping | Zz 闭眼 | 休眠/夜间 |
| surprised | 张嘴惊讶 | 惊喜彩蛋 |

### 步骤
1. **生成表情图**:用学园立绘 whale_chan.png 头像做基础,生成 9 张表情变体(240×240 PNG,圆形安全区内;工具:本地图像编辑/AI 生图由用户提供或裁剪)
2. **打包资产**:按 xiaozhi-assets-generator(github.com/78/xiaozhi-assets-generator)的 manifest 格式打包
3. **托管**:放学园服务端静态目录(`http://IP:8003/xiaozhi/assets/...`)或临时 GitHub/局域网 HTTP
4. **下发**:对话中发 MCP 指令 `self.assets.set_download_url(url)` → 设备自动下载写入 assets 分区 → 重启生效
5. **验证**:触发各表情场景,屏幕显示鲸鱼娘对应表情

### 风险与回滚
- 资产包格式错误 → 设备回落官方表情(set_download_url 指回官方即可)
- 分区 8MB 足够(1280KB map + 表情图集远小于此)

## 阶段三:圆形屏幕适配与联调验收

1. **圆形适配规则**:所有表情/状态图**居中圆形构图**,四角留空(不做方形全屏图);文字类 UI(LVGL)由官方板级已适配,不动
2. **联调清单**:
   - [ ] 唤醒→对话走学园服务端(DeepSeek 学园人设)
   - [ ] 天气/音乐等 MCP 工具仍可用
   - [ ] 表情全场景触发正确(9 张逐一)
   - [ ] 圆屏无变形/无裁切
   - [ ] 断网回落提示
   - [ ] 冉冉**独立操作**完成一轮:唤醒→对话→错题重练(联学园网页数据)
3. **验收标准**:冉冉不用大人帮忙,完成「唤醒→对话→答题→看到表情变化」全流程
