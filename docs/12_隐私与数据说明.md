# 12 · 隐私与数据说明(小鲸灵学园)

> 原则:孩子的学习数据**只存在家里**,不上传任何第三方(DeepSeek 对话除外——发送的文本不含姓名)。

## 数据清单与位置(全部 gitignore)

| 数据 | 位置 | 谁可见 |
|---|---|---|
| 学习档案(XP/关卡/错题/调整理由) | `data/learn_{child}.json` | 孩子端使用;家长端经 token 只读 |
| 家长 PIN | `data/parent_auth.json`(SHA256+salt,5 次失败锁 15 分钟) | 仅服务端校验 |
| 对话日志 | `data/chat_log.jsonl`(超 1MB 轮转) | 家长端只读 |
| 头像墙档案名 | `config/profiles.json`(入库,可改名) | 所有人可见名字 |

## 家长数据主权(PIN 保护)

- **导出**:`/api/parent/export/{child}`(学习档案原始 JSON)/ 总览卡「下载学习报告」(按周聚合)
- **清除**:`POST /api/parent/purge/{child}`(不可恢复——清除前建议先导出)
- **改名**:总览卡「✏️ 改名」

## 副屏与伴听

- 副屏(sub.html):只读摘要,60s 轮询,**不镜像孩子可操作界面**,不出局域网。
- 伴听:音频只在家长设备浏览器出声,独立音频通道,不占用孩子端会话。

## DeepSeek 说明

- 聪明模式下对话文本发送至 DeepSeek API(见 .env);发送内容不含孩子姓名与学校等个人信息。
- 台词模式(离线)完全不联网。
