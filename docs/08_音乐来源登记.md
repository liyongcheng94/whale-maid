## 获取方式

```bash
# 1. 启动 go-music-dl web 服务（v1.1.7 Windows 二进制已验证）
music-dl.exe web -p 8099 --no-browser        # 首次需 /music/setup 初始化

# 2. music_fetch.py 一站式搜索+下载+入库（推荐）
python scripts/music_fetch.py --search "歌名"           # 跨平台搜索
python scripts/music_fetch.py --get <序号> --group songs # 下载+ASCII重命名+登记歌单

# 3. 或手动：搜索卡片 data-* 参数 POST /music/api/downloads/queue
```

## 命名规范

`{组}_{序号}_{ascii歌名}.m4a`——全 ASCII 小写下划线；中文歌名只存在于 `config/playlist.json` 的 title/alias 字段。
