## 制作流水线

```bash
# 1. 每句用 CosyVoice2 克隆音色离线生成 wav（15~30s 参考音频，见 docs/03）
#    初版可先用任意 TTS 占位
# 2. 转 ogg（仓库工具，需 ffmpeg + ffmpeg-python）
cd src/xiaozhi-esp32/scripts/ogg_converter
python xiaozhi_ogg_converter.py   # 批量：输入 wav 目录 → 输出 ogg
# 3. 放入资产目录
cp output/*.ogg ../../main/assets/common/
# 4. 重建固件（gen_lang 自动产出 OGG_* 符号）
python scripts/build.py whale-maid --language zh-CN --wake-word wn9_xiaoaitongxue
```

## 代码触发点（whale_maid_board.cc 增量）

- 摸头 OnPressDown：随机池 [2,3]（srand(esp_timer_get_time()) 两选一）
- 摸肚 OnPressDown：#4
- 覆盖内置音效：#9 low_battery 直接替换 assets/common/low_battery.ogg（同名覆盖，无需改代码）
- 其余触发点挂在 Application 事件回调（V2 增量，首版只做摸头/摸肚/低电量三个）

## 禁区

- 文件名禁大写/空格（asm 符号生成约束）
- 单句时长 ≤6s、码率由 converter 默认（assets 分区余量校验：idf.py partition-table）
- 台词不得违反 CC BY-NC-SA 人设边界（不商用、不改人设核心设定）
