## ⚠️ 上电三红线（违反任何一条都可能烧板）

1. **MT3608 上电前必须先空载调压**：模块 OUT+ 接万用表，USB 侧先供电，旋钮调到 **5.00V ±0.05V**，**再**接负载。带载调压会瞬间过压烧 ESP32。
2. **18650 正负极反接 = 立即烧 TP4056**：接线后、上电前，万用表测电池盒输出：红笔 B+ ≈ 3.0~4.2V。
3. **5V 与 3.3V 绝不混接**：OLED/INMP441/MAX98357A 全部接 3.3V 轨（ESP32 引脚是 3.3V 逻辑），只有 MT3608 输出给 ESP32 的 5V VIN。

## 一、接线总表（对照 main/boards/whale-maid/config.h）

主控：ESP32-S3-DevKitC-1 **N16R8**。引脚与 bread-compact-wifi 完全一致（复用成熟链路，符合 AGENTS.md「不改现有板引脚」），仅新增 GPIO21 第二触摸区。

### 音频 I2S（Simplex 双总线，config.h 实据）

| 信号 | ESP32 GPIO | INMP441 引脚 | 备注 |
|---|---|---|---|
| MIC WS | **4** | WS | 左声道采集（L/R 接 GND） |
| MIC SCK | **5** | SCK | |
| MIC DIN | **6** | SD | |
| MIC L/R | — | L/R→GND | 左声道；悬空=右声道（I2S 时序错位） |
| MIC VDD/GND | 3V3 / GND | | |

| 信号 | ESP32 GPIO | MAX98357A 引脚 | 备注 |
|---|---|---|---|
| SPK DOUT | **7** | DIN | |
| SPK BCLK | **15** | BCLK | |
| SPK LRCK | **16** | LRC | |
| SPK GAIN | — | GAIN 悬空 | 默认 9dB；吵了改接 GND(12dB)或 VIN(6dB) |
| SPK SD | — | SD→VDD（默认响） | 若接 GPIO 控制静音需改 config，V2 再说 |
| SPK VIN | **5V 轨** | | MAX98357A 支持 2.5~5.5V，接 5V 声更大；喇叭 ≤3W |

### OLED（I2C，SSD1306 128x64，地址 0x3C）

| OLED | ESP32 GPIO |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCL | **42** |
| SDA | **41** |

- 41/42 占用 S3 的硬件 JTAG(39-42)：不影响 USB 烧录与串口监控（43/44/19/20），只是没法 JTAG 硬调试——摆件用不到，接受。
- 买了 SH1106 变体也没关系：config 走 `CONFIG_OLED_SH1106_128X64` 分支即可（config.h:45-47 实据）。

### 触摸区 ×2（〔2026-11-16 审校修正〕必须经 TTP223，铜箔不可直连 GPIO）

| 位置 | ESP32 GPIO | 电极做法 |
|---|---|---|
| 头顶（呆毛内） | **47** | 铜箔贴呆毛内壁作**延长电极** → 焊到 **TTP223 模块感应面**，模块 OUT→GPIO47，VCC/GND→3V3/GND |
| 肚皮 | **21** | 同上，第二颗 TTP223，OUT→GPIO21（需新板目录注册，见 §五） |

- **为什么不能铜箔直连**：`compact_wifi_board.cc:158` 的 `touch_button_(TOUCH_BUTTON_GPIO)` 是普通数字 `Button` 组件，只认高低电平；ESP32-S3 内部触摸外设仅 GPIO1-14 支持，47/21 无电容感测能力。铜箔直连=永远无触摸事件。
- 触摸阈值在 Button 组件内建；铜箔面积 ≥1cm²，TTP223 灵敏度即可覆盖。
- GPIO47/21 均非 strapping（0/3/45/46 才是），47 不在 JTAG 段，21 不在 USB(19/20) 段——无冲突，本地核实。
- BOM 对应：docs/01 A6 TTP223×2 + A13 铜箔（v2.1 已恢复）。

### 电池与电源（含负载共享，审校项 #2 修复；〔2026-11-16 审校修正〕取电点=USB VBUS，不是 TP4056 OUT+）

```
USB-C VBUS(5V) ──┬──► TP4056 IN+（充电管理；B+/B- 只接电池，OUT+/OUT- 悬空不接负载）
                 │
                 ├──► 1N5819 正极 → 负极 ──────┐
                 │                             ├──► 负载轨 5V_C
                 └──[100kΩ]──► AO3401 G        │
                        │                      │
                        └──[100kΩ]──► GND 下拉 │
18650 B+ ──────────► AO3401 S ──► D ──────────┘
```

- **为什么取电必须是 USB VBUS 而非 TP4056 OUT+**：标准 TP4056 模块的 OUT+ = 经保护电路后的**电池节点**（≈3.0~4.2V），USB 插着也到不了 5V。若 G 接 OUT+：Vgs≈0 → P-MOS 永远关断 → 拔 USB 即断电；负载挂 OUT+ = 充放同路原样保留。v3 任务书 §0 的原始接法（USB 5V 取电）才是对的，本表此前画偏，已修正。
- 原理：USB 在 → G 被 VBUS 拉高（≈5V）> BAT+ → P-MOS 截止，电池脱载充电，TP4056 终止电流可达阈值 → 充满能正常截止（蓝灯、BAT+≈4.20V）；USB 拔 → G 被 100k 下拉至地 → Vgs≈-BAT+ → 导通，电池接管。门极串 100k 是防止 USB 掉电后栅极向 VBUS 倒灌。
- 体二极管方向已核对：S=BAT+ / D=负载轨，USB 供电时负载轨(≈4.7V) > BAT+，反偏无倒灌。
- AO3401 引脚：SOT-23，栅极 G=pin1，其余 S/D 对称可任意。焊接注意热缩管绝缘。
- 电池直出 3.7~4.2V → MT3608 升到 **5.00V**（空载先调！）→ ESP32 的 5V/VIN 引脚。板载 LDO 转 3.3V 供外设。
- 总开关串在 MT3608 输出后、ESP32 VIN 前（断电=彻底关机，无待机耗电）。
- **验收门**：USB 充电时 BAT+ 电压爬升，充满 TP4056 蓝灯亮、BAT+≈4.20V；拔 USB 后负载不死机（MOS 切换 <10ms，ESP32 无感）。**台架步骤 6 若「拔 USB 即灭」先查本节取电点。**

### 烧录与串口

- 用板自带的 **USB 口（CH343/USB-CDC）**：S3 原生 USB 支持烧录+monitor，无需外接 USB-TTL。
- BOOT(GPIO0) 键按住再按 RESET 进下载模式的场景：S3 + 原生 USB 口通常免手动 BOOT；若烧不进：按住 BOOT → 插 USB → esptool 检测。
- 排线建议：烧录阶段全部用杜邦线在面包板搭，**外壳装配前先台架全绿**。

## 三、固件：新建 whale-maid 板目录（不 fork 任何现有板引脚）

### 为什么必须新建（AGENTS.md 红线 + OTA 安全）

- AGENTS.md：**"Never alter an existing board's pins"**——GPIO21 触摸区需要新增引脚定义，bread-compact-wifi 不许动。
- OTA 红线：编译产物携带板身份（config.json `type`），若伪装成 bread-compact-wifi 且 IO 配置不同，将来任何一次 OTA 都会被官方固件覆盖成引脚错乱的固件——**变砖级风险**。故 `type: "whale-maid"` 独立命名。

### 四件套（main/boards/whale-maid/）

1. `config.json`：
```json
{
    "type": "whale-maid",
    "target": "esp32s3",
    "builds": [
        { "name": "whale-maid", "sdkconfig_append": ["CONFIG_OLED_SSD1306_128X64=y"] }
    ]
}
```
（16MB Flash 是项目默认，无需 append 覆盖；不要在此选语言/唤醒词。）

2. `config.h`：完整文件见 `firmware/patches/0001-whale-maid-board.patch`（apply 后位于 main/boards/whale-maid/）。要点：拷贝 bread-compact-wifi/config.h 全部定义，追加：
```c
#define TOUCH_BELLY_BUTTON_GPIO GPIO_NUM_21
```
删除 VOLUME_UP/DOWN 定义（我们没接音量键——音量由对话指令控制）。

3. `whale_maid_board.cc`：完整文件在 patch 内。以 compact_wifi_board.cc（188 行，本地全读）为模板：
   - 删掉 volume_up_button_/volume_down_button_ 两个成员与 InitializeButtons 里的对应段；
   - 新增 `Button touch_belly_button_(TOUCH_BELLY_BUTTON_GPIO)`，OnPressDown/OnPressUp 同 head 区绑定 Start/StopListening（把「触摸肚皮说话」做成体验彩蛋）；
   - 其余（SSD1306 初始化/NoAudioCodecSimplex/SingleLed）原样保留。
   - 文件尾 `DECLARE_BOARD(WhaleMaidBoard);`——全仓唯一。

4. `README.md`：patch 内含。

> **一键落地**：`bash scripts/install_src.sh` 自动拉双仓 + 应用 patch（含 git 克隆失败自动 tarball 降级）。

## 四、彩蛋 20 句音效（ogg 编译期嵌入链）

1. 写 20 句鲸鱼娘台词（见 docs/06_彩蛋台词.md；〔2026-11-16 更正〕docs_tmp_eggs.md 已被 docs/06 取代。生日冲刺版人设/台词见 docs/07 与 config/persona.md：称呼女儿「冉冉姐姐」）。
2. TTS 生成 wav（服务端 CosyVoice2 克隆音色离线预生成，见 docs/03 §彩蛋），或任意 TTS 初版。
3. `python scripts/ogg_converter/xiaozhi_ogg_converter.py` 批量转 ogg（需 ffmpeg + `pip install ffmpeg-python`）。
4. ogg 文件放入 `main/assets/common/`（CMake `file(GLOB COMMON_SOUNDS)` 自动打包）。
5. 重新构建 → `Lang::Sounds::OGG_<文件名大写>` 自动生成 → 在触摸回调里 `PlaySound(Lang::Sounds::OGG_<名字>)`。
6. **分区校验**：`idf.py partition-table` 确认 assets 分区装得下；20 句 ×~15KB ≈ 300KB，16MB 表富余。

**禁区**：不要走 p3 路线（固件 main/ 无 .p3 引用，p3_tools 是独立工具）；不要手改 `main/assets/lang_config.h`（gen_lang.py 生成物）。

## 六、回滚与人工接管点

- 任何一步台架红灯且 10 分钟无法定位 → 回滚到上一绿步，隔离新接入的外设单测。
- 烧录变砖（极端）：S3 有 USB 下载模式兜底，按住 BOOT 重插 USB 可重烧，不依赖串口芯片。
- 需要人工接管：MT3608 调压（万用表读数）、电池反接检查、触摸电极贴合手感——这三步机器验不了。
