## 三、电子件与形象的结合点（对照 docs/02/04）

- **OLED 眼窗（方案 A）**：眼部区域开 0.96″ 屏窗，屏上跑动态眼睛；腮红/嘴保留为壳面涂装。方案 C 兜底 = 整脸涂装（按设定图画脸）。
- **触摸区 1 = 头饰+呆毛**：铜箔延长电极贴头饰内壁，TTP223 → GPIO47。
- **触摸区 2 = 围裙下方腹部**：电极贴围裙对应壳内壁，TTP223 → GPIO21。
- **麦克风孔 ×3**：左发浪区域（观感最不破坏形象的位置）。
- **喇叭出声孔**：裙底第二层裙撑内隐藏孔阵，仰视不可见。
- **设备舱**：裙底 + 底座内：18650 / TP4056 / MT3608 / 负载共享板；Type-C 充电口与电源开关开在底座后侧。
