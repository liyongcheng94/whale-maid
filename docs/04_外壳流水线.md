# 04 · 外壳改造流水线

> 输入：MakerWorld 2899554 原始 3MF（115MB，本地在案）。
> 输出：可打印的挖腔/分件版 3MF + 打印店询价单 + 装配图纸。
> 核心矛盾已实测：**模型是 155 个互不焊接的封闭壳**，不能「整体挖腔」。

## 一、模型事实卡（scripts/analyze_3mf_v3.py 实测，2026-11-16）

| 项 | 数值 | 影响 |
|---|---|---|
| bbox | 110.02 × 77.44 × 128.00 mm | 放大一倍后 220×155×256mm，需大幅重新考虑支撑与层高 |
| 顶点/三角形 | 2,543,819 / 5,000,027 | 高面数，Blender 操作会卡，先 Decimate 50% 再改，改完不可还原原细节 |
| 独立封闭壳 | **155 个**（Top5: 24.8/17.8/17.3/17.3/6.7cm³） | **单壳最大才 45.9×31.7×53.7mm——没有任何一个壳大到能容纳电路舱** |
| 碎壳(<1cm³) | 127 个 | 装配时全部删除（装饰性碎件，打印出来也是掉渣） |

| 原打印参数 | Bambu H2C、0.4 喷头、0.2 层高、15% 填充、无支撑、双色 PLA | 上传者能无支撑打=他的摆放角度下自支撑；我们挖腔后角度必变 |

## 二、改造策略决策

**方案：跨壳布局（不合并网格）**

理由：布尔合并 155 壳需要 Manifold/精确布尔且 500 万面极易失败；而鲸鱼娘是「头+身+裙+鳍+尾」的天然分件结构，Top5 壳对应这些部件。直接利用：

| 舱位 | 容纳 | 所在壳 |
|---|---|---|
| **裙内主舱** | ESP32-S3 devkit + 面包板阶段临时件 | 裙壳（预计是 Top3 之一，17.3cm³）——需挖空 |
| 头部 | 触摸电极（铜箔贴内壁） | 头壳 |
| 肚皮 | 触摸电极 | 身体壳 |
| 底部开孔 | 扬声器出声孔 + USB 充电口 + 开关 | 裙底 |

**风险与对策**：
- 壳体壁厚未知（Hi3D 生成件壁厚可能不均匀）→ 打印店先打 0.3mm 壁厚测试件或直接 15% 填充实心裙。
- 硬件尺寸预算：DevKitC-1 ≈ 25.4×54.2mm；OLED 27×27mm；18650 高 65mm 直径 18mm——**18650 是最长的硬约束**，裙内竖放。
- 若裙壳实际容积 <250cm³（18650+devkit+走线最小需求）：降级方案 B——底座舱（另打一个底座放电池与主板，鲸鱼娘成为可分离摆头）。

## 三、Blender 操作流（人工执行，预计 3~5 天）

0. 前置：装 Blender 4.x + Import 3MF（自带的 obj/ply 转换或装 io_scene_3mf 插件）。
1. **导入与减面**：导入后先 Decimate 修饰器 50%（2.5M→1.25M 顶点），台架阶段够用；终版可回 3MF 原始面。
2. **清碎壳**：Edit Mode → Select All by Trait → Loose（阈值按体积）→ 删 127 个碎壳。
3. **定位壳归属**：Outline 里逐个壳 isolate 显示，对照 MakerWorld 渲染图给壳命名（head/dress/body/tail...）。
4. **挖腔**：对裙壳：Add Cube 布尔 Difference，尺寸 = 硬件包络 + 5mm 走线余量。挖腔方向从裙底开口向上（保留外观面）。
5. **开孔**：布尔 Difference 打 3 类孔：喇叭孔阵（裙底，Φ2×9 宫格）、USB-C 口（裙底后方，8×4mm 通孔）、开关孔（4×2mm）。
6. **屏幕窗口**（脸部方案 A 时）：面壳前部挖 27×30mm 矩形窗口 + OLED 支架柱；屏幕后置。**脸部 A/B/C 未拍板前此步挂起**（Open objective）。
7. **分件检验**：全模型 3D Print Toolbox 插件查 Manifold/壁厚/悬垂；导出分件 STL。
8. **交付打印店**：每件导出 3MF（含双色映射说明）+ 一页「打印参数卡」（见 §四）。

## 四、打印店询价与参数卡（给店员的）

- 工艺：FDM 双喷头（Bambu H2C 或同级别 AMS）才能双色；单色机则全白+手涂。
- 材料：PLA Basic（对齐原参数）；撑材料同 PLA。
- 层高 0.2mm、壁 2 loop、填充 15%（裙壳可 20% 抗挖腔薄壁）、支撑：挖腔后需 tree support，接触面层高改薄、支撑线距紧（评论区实测经验）。
- 放大决策：**首版 1:1 原尺寸打印验证装配**，成功后放大 1.5~2 倍再打终版（放大一倍=220×155×256mm，多数店最大打印尺寸 256mm³ 需切件）。
- 询价口径：总耗材估 150~250g 双色 + 支撑，市价 ¥40~80；切件加收。

## 五、装配顺序（对应 docs/02 台架完成后）

1. 电池盒+TP4056+MT3608+MOS 组件先在舱外连好线、热缩管绝缘。
2. 18650 竖放入裙舱底部，其他组件叠放，OLED 从面壳窗口（或方案 B 胸口）装入。
3. 触摸铜箔贴头顶/肚皮内壁，线引至主舱。
4. 合件：若壳间有缝隙，热熔胶点固定（可逆）。
5. 终验：触摸灵敏度（隔着壳壁可能衰减，电极面积加大到 2cm²）、喇叭音量、充电口插拔。

## 六、验收门

- [ ] 改造版 3MF 能在切片器里切出且双色映射正确
- [ ] 硬件干装（不接线）所有部件能进舱
- [ ] 打印件合件后无肉眼可见错位
- [ ] USB-C / 开关 / 喇叭孔位置实测可用
- [ ] 摸头/摸肚在壳装好后仍灵敏

## 假设与边界

- 壳-部件对应关系待 Blender 实操确认（分析脚本只能给体积/尺寸，不能给语义）。
- 面部窗口取决于脸部方案 A/B/C 拍板（Tier 2 前）；方案 C 无屏则跳过步骤 6。
- 打印店工艺不确定（双色机保有率低）→ 先电话询价再改模型，避免白改。
