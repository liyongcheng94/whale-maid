# 14 · 阶段一步骤单:服务端部署 —— Windows 原生版(推荐,免 WSL/Docker)

> 2026-11-19 更新:实测**本机 Windows 原生 Python 即可跑 xiaozhi-server**(纯 Python 应用,Docker 只是官方省事封装)。
> 家里这台机器已有 Python 3.11/3.12/3.13,服务端依赖 torch 2.2.2 兼容 3.11 → 用 **Python 3.11 专用 venv**。
> AI 已在本机完成:venv 创建 + 依赖安装(见下 S1');以下步骤为复现记录与**以后重装指南**。

## Windows 原生部署(已完成 ✅)

| 步 | 命令(在 `src/xiaozhi-esp32-server/main/xiaozhi-server/` 执行) | 说明 |
|---|---|---|
| S1' | `py -3.11 -m venv .venv311` | 服务端专用虚拟环境(与网页版 3.13 隔离) |
| S2' | `.venv311\Scripts\python -m pip install -r requirements.txt` | 39 项依赖(torch CPU ~200MB,一次性) |
| S3' | 配置 `data/.config.yaml`(拷 `firmware/server/xueyuan.config.yaml` 改名+填 DeepSeek key) | 学园人设+DeepSeekLLM |
| S4' | `.venv311\Scripts\python app.py` | 启动;日志出现 OTA/Websocket 地址即成功 |

### 已知注意点(Windows 原生)
- `opuslib_next` 需要 **libopus DLL**:如启动报找不到 opus,从 ffmpeg/opus 官方 release 拷 `libopus-0.dll` 到 venv `Scripts\` 或 PATH(AI 出现此报错时自动处理)
- 本地 ASR(FunASR)首次运行下载模型 ~1GB(modelscope);**先不装也行**——ASR 可临时切云端/浏览器端,设备连通后再补
- 防火墙放行 8000(WS)/8003(OTA):AI 给命令,管理员 PowerShell 执行
- PC 从不睡眠:设置→系统→电源
