# 14 · 阶段一步骤单:WSL2+Docker 服务端部署(用户执行,AI 陪跑)

> 目标:微雪设备从 xiaozhi.me 官方云切换到**家里学园服务端**(DeepSeek+学园人设)。
> 执行方式:**你按顺序跑命令,AI 实时看输出排障**。每步完成后说一声,我看日志确认再给下一步。
> 全程约 40-60 分钟(大部分是下载等待)。

## S1 · WSL2(管理权限 PowerShell,非 Git Bash)

```powershell
wsl --install -d Ubuntu-24.04
```
- 装完**重启电脑**,首次进入 Ubuntu 设一个用户名密码(记住密码,sudo 要用)
- 验证:开始菜单打开「Ubuntu」能进 shell

## S2 · Docker(在 Ubuntu 里)

```bash
sudo apt update && sudo apt install -y docker.io docker-compose-v2
sudo usermod -aG docker $USER
```
- **注销再登录**(让 docker 组生效)
- 验证:`docker ps` 不报权限错误

## S3 · 拷贝服务端代码进 WSL

在 Ubuntu 里(把 Windows 的代码挂载过去性能差,拷进 WSL 本地):

```bash
mkdir -p ~/xueyuan && cp -r /mnt/d/project/whale-maid/src/xiaozhi-esp32-server/main/xiaozhi-server ~/xueyuan/
cd ~/xueyuan/xiaozhi-server
```

## S4 · 放入 DeepSeek 配置(学园人设)

AI 已预备配置文件:`firmware/server/whalemaid.config.yaml`(含 DeepSeek key 占位+学园人设)
- 把它拷到 `data/.config.yaml`(AI 给出精确命令,或你在文件管理器操作 `\\wsl$\Ubuntu-24.04\home\<你>\xueyuan\`)
- **编辑填入 DeepSeek key**(和网页版同一个 key)

## S5 · 启动服务端

```bash
docker compose up -d
docker compose logs -f
```
- 看到 `Websocket地址是 ws://<IP>:8000/xiaozhi/v1/` 即成功(Ctrl+C 退出日志)

## S6 · 告诉 AI 两件事

1. Ubuntu 里跑 `hostname -I` 的输出(设备要连的 IP)
2. 「日志里出现 Websocket地址」了

之后 **AI 接管**:设备激活码注册到服务端管理台 → 设备 OTA 切换 → 对话切 DeepSeek → 全链路验证。

## 常见坑(遇到就说,AI 有解法)

- WSL2 装完重启报「虚拟化未开启」→ BIOS 开 VT-x/虚拟化
- docker compose 镜像拉取慢 → compose 已配国内镜像源(ghcr.nju.edu.cn)
- 设备连不上服务端 → Windows 防火墙放行 8000/8003(AI 给命令)
- WSL 重启后 IP 变化 → AI 出「固定 IP/防火墙脚本」
