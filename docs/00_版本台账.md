**仓库拓扑（2026-11-17 统一管理，以 fork 为唯一事实源）**：
```
liyongcheng94/whale-maid (fork，事实源) ← 人工 commit+push
    ↑ 回写 firmware/patches/*.patch（sync_firmware.sh 自动 + 树哈希自验）
src/xiaozhi-esp32 (基座，本地构建用)
    ├── origin = 78/xiaozhi-esp32（上游，只读）
    └── whale-maid 分支 = origin/main + 板级提交
```
- 同步方向：上游更新 → 基座 rebase → 脚本回写 patch 到 fork → 人工提交推送（push 需本机 SSH key，沙箱不可代推）
- ⚠️ 教训：`git fetch fork` 会覆盖 FETCH_HEAD，rebase 必须用显式哈希或 `origin/main`
- patch 文件字节级差异（commit 头部哈希/时间戳）无意义，以树哈希等价为判断标准

**⚠️ IDF 版本修正记录**：早期网页调研误记「ESP-IDF 5.4+」，本地 AGENTS.md 明确 **IDF 5.x 不支持，最低 v6.0.1，推荐 release/v6.1**。已推翻。

**AGENTS.md 硬规则摘录**（src/xiaozhi-esp32/AGENTS.md，本地核实）：
- 一个 build 只准一个 `DECLARE_BOARD(...)`。
- **禁止修改现有板型引脚**——OTA 兼容性依赖板身份；硬件不同必须新建板目录。
- 构建链耦合：`config.json → scripts/build.py → main/Kconfig.projbuild → main/CMakeLists.txt → 板源码/config.h`，新增板型每环都要更新。
- 不手改生成物：`build/`、`managed_components/`、`sdkconfig*`、`main/assets/lang_config.h`。
- 禁止在板 config.json 中选语言/唤醒词（用户构建选项，走 build.py 参数）。

### bread-compact-wifi 引脚表（main/boards/bread-compact-wifi/config.h，59 行全读）
| 功能 | GPIO | 备注 |
|---|---|---|
| MIC I2S WS/SCK/DIN | 4 / 5 / 6 | INMP441 |
| SPK I2S DOUT/BCLK/LRCK | 7 / 15 / 16 | MAX98357A |
| BOOT 键 | 0 | strapping 脚，按下进配网 |
| 触摸键 | 47 | 单键，**经 TTP223 模块数字输出**（Button 组件=数字电平，S3 触摸外设仅 GPIO1-14） |
| 音量+/− | 40 / 39 | （我们砍掉，见 docs/02） |
| OLED SDA/SCL | 41 / 42 | 占 JTAG(39-42)，不碍 USB 烧录(43/44) |
| 板载 LED | 48 | WS2812/单色 |
| LAMP (MCP 演示) | 18 | 弃用（未接线；肚皮触摸走 GPIO21） |

### 新板（whale-maid）引脚改动
- 保留 bread-compact-wifi 全部引脚不变（复用其成熟链路）；
- 新增第二触摸区 GPIO21（空闲、非 strapping、不占 USB/JTAG）；
- LAMP GPIO18 保留或弃用，见 docs/02 §触摸。

### 其他硬件事实
- OLED：SSD1306/SH1106 128x64，I2C 地址 **0x3C**（esp_lcd 默认，compact_wifi_board.cc:54），400kHz。
- 编解码：**无独立 codec**（NoAudioCodecSimplex，compact_wifi_board.cc:174）——INMP441 直采 + MAX98357A 直推，正是我们 BOM 的两颗芯片。
- I2S 采样率：IN 16000 / OUT 24000（config.h:6-7）。
- Flash：项目默认 16MB + partitions/v2/16m.csv（sdkconfig.defaults 核实）——**N16R8 正好匹配，无需 sdkconfig_append 覆盖**。
- ESP32-S3 唤醒引擎：Kconfig `USE_AFE_WAKE_WORD` depends on (S3/P4/S31) && SPIRAM（Kconfig.projbuild:1006-1011）→ N16R8 满足。
- strapping 脚：0/3/45/46——接线时避开或按 datasheet 处理。

## 四、构建命令备忘（custom-board_zh.md 权威流程）

```bash
source ~/esp-idf/export.sh
python scripts/build.py --list-boards                 # 确认 whale-maid 注册成功
python scripts/build.py --list-wake-words             # 实机确认 wn9_xiaoaitongxue 可选

  --language zh-CN \
```

## 五、音效资产管线（本地源码核实，纠正审校项 #1）

- **编译期嵌入**：`main/assets/common/*.ogg` 与 `main/assets/locales/zh-CN/*.ogg` 由 CMake `file(GLOB ...)` 打包 → `gen_lang.py` 生成 `Lang::Sounds::OGG_*`（asm 符号 `_binary_*_ogg_start/end`）→ `audio_service_.PlaySound()` 播放，`ogg_demuxer.cc` 解码。
- **固件 main/ 中无任何 .p3 引用**；`scripts/p3_tools/`（4字节头+Opus 流）是独立工具，用途待 server 仓核实后补录本表。
- 彩蛋 20 句正确路线：**wav → scripts/ogg_converter/xiaozhi_ogg_converter.py（需 ffmpeg）→ assets/common/*.ogg → 重新编译嵌入**。
- 新增音效后须重跑 `gen_lang.py` 或让 CMake 重跑（build.py 会处理），并核对 16MB 分区余量。

## 八、假设与边界

- **无 AEC 非全双工**：机器人说话时麦克风仍开着但体验上打断会含混——这是 I2S 无 codec 方案的固有属性，属正常体验，不是 bug。
- 本沙箱无 GPU/ESP-IDF：所有 GPU 与编译验证须在用户真实 WSL 终端执行（教训：bwrap 沙箱内 NVML 报 GPU blocked，不可信）。
- esp-sr 唤醒模型的 sdkconfig 选项名未在本地确认（managed_components 未下载）——以 `--list-wake-words` 实机输出为准。
- 服务端 v0.9.8 源码未落本地前，docs/03 中引用的配置路径（config.yaml/docker-compose.yml）以克隆后核读为准。
- MakerWorld 2899554 授权 **CC BY-NC-SA 4.0**：自用/送人 ✅，销售 ❌（授权链：溟月原作→ZipZipPipe 二创→lucyundead 3D）。
- **歌单音频（2026-11-17）**：全部经 go-music-dl 从 Bilibili 公开音频下载，**个人非商用**（送人摆件自用）；哈基米类为网络二创梗曲，版权归原作者。来源实测矩阵与逐曲登记见 `docs/08_音乐来源登记.md`。go-music-dl 项目声明「仅供个人学习研究」，同口径遵守。
